# EliteConnect AI
Architect top-tier proposals and emails that command authority and close deals.

## Overview
EliteConnect AI is a premium, high-performance proposal engineering tool built for freelancers to generate personalized, high-conversion pitches and client communications in seconds. It goes beyond simple text generation by analyzing client requirements and adapting the strategic tone for maximum impact.
 
## 🎥 Project Demo Video
Watch the full demo here: https://youtu.be/r9721VLzrVg?si=nPyrFz6Q4-Ez1Tr6

## Key Features
. Dynamic Model Discovery: Automatically detects and integrates the best available Google Gemini AI models authorized for your API key.
. Adaptive Strategy: Auto-detects client psychology (e.g., Fear, Speed, Quality) to tailor proposals.
. Format Flexibility: Generate professional Project Proposals or polished Client Emails.
. Multimodal Context: Supports analysis of PDF CVs, Word documents, and reference screenshots for highly relevant output.
. Secure Architecture: Built with security-first practices, utilizing environment variables (.env) and strict Git sanitization.

## Technical Stack
Frontend: Streamlit (Custom Glass-Themed UI)
AI Engine: Google Gemini API (Dynamic Integration)
Document Processing: python-docx, PyPDF2
Environment Management: python-dotenv (Security-hardened)
