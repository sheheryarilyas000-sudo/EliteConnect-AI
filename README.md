## 📖 Overview
**EliteConnect AI** is a premium, high-performance proposal engineering tool built for freelancers. It goes beyond simple text generation by analyzing client requirements and adapting the strategic tone for maximum impact, allowing you to generate personalized, high-conversion pitches in seconds.

---

## ✨ Key Features
- 🤖 **Dynamic Model Discovery:** Automatically detects and integrates the best available Google Gemini AI models authorized for your API key.
- 🧠 **Adaptive Strategy:** Auto-detects client psychology (e.g., Fear, Speed, Quality) to tailor proposals perfectly.
- 📄 **Format Flexibility:** Generate professional Project Proposals or polished Client Emails instantly.
- 🖼️ **Multimodal Context:** Supports analysis of PDF CVs, Word documents, and reference screenshots for highly relevant output.
- 🔒 **Secure Architecture:** Built with security-first practices, utilizing environment variables (`.env`) and strict Git sanitization.
