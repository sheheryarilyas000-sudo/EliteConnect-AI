# EliteConnect AI
*Architect top-tier proposals and emails that command authority and close deals.*

## Overview
EliteConnect AI is a high-performance proposal engineering tool designed for freelancers to generate personalized, high-conversion pitches in seconds. 

## Key Features
- **Adaptive Strategy:** Auto-detects client psychology (Fear, Speed, Quality).
- **Format Flexibility:** Generate Project Proposals or Client Emails instantly.
- **Multimodal Analysis:** Supports PDF CVs, Word docs, and Reference Images for context.
- **PDF Export:** Branded, clean, and professional document generation.

## Technical Stack
- **Frontend:** Streamlit
- **AI Engine:** Google Gemini 1.5 Flash
- **Document Processing:** FPDF, python-docx, PyPDF2
